# Supercuper

Första webbkonceptet för `supercuper.se`: en responsiv startsida för fotbollscuper och matchcamper.

## Kör lokalt

```bash
npm install
npm run dev
```

## Innehåll före publicering

- Ersätt demonstrationsarrangemang med riktiga datum, platser, klasser och villkor.
- Koppla intresseformuläret till vald e-post-/CRM-tjänst. Det visar nu endast en lokal bekräftelse.
- Bekräfta kontaktadress och juridiska sidor.
- Ersätt demonstrationsbilder eller behåll dem med korrekt licenshantering. Bildreferenserna kommer från Pexels-sidorna för foto 28260833, 28652713, 33613894, 38040080 och 28582037.

Designen hämtar riktning från Luxcupers luftiga, bilddrivna presentation men använder egen identitet, färgpalett, struktur och copy.

## Varumärke

Huvudmärket är `public/logos/supercuper-main.jpg` och används diskret i sidhuvud och sidfot. Cupmärkena ligger separat i samma katalog och ska bara användas tillsammans med respektive arrangemang.

- Super Cuper Navy: `#002D62`
- Super Cuper Orange: `#FF4B0B`
- Deep Navy: `#001F46`
- Bright Orange: `#FF6414`
- White: `#FFFFFF`
- Off-white: `#FAFAF8`
